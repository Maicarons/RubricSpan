# wasm/ —— 浏览器离线推理（备选模式，M6）

技术方案第 10 章 · 方案 B：轻量模型（60M 蒸馏版 / INT8 量化版）经
ONNX → WASM 工具链转换后，由前端在浏览器内加载，实现**无网络环境的单题评分演示**。

## 规划结构（M6 构建）

```
wasm/
├── README.md           # 本文件
├── build/              # 转换脚本（ONNX → WASM，M6 编写）
├── pkg/                # 构建产物（不入库）
└── README-usage.md     # 离线演示使用说明与能力边界（M6）
```

## 约束与边界

- 与在线端**共用同一套评分配置（JSON）与一致的混合评分路线**，保证结果可比；
- 仅用于单题 / 小批量演示场景，推理速度慢于 GPU 服务，不替代生产后端；
- 模型产物（`models/wasm/`）遵守 `../contracts/model-artifacts.md`。

## 离线场景降级

标准答案解析在离线场景下降级为"手动编辑评分配置 JSON"
（或调用本地大模型，如有），见技术方案 §10.3。
