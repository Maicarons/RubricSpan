## 1. 评测设计

- 数据：`data/processed/mrc_test.jsonl` 中 origin=full 的真实完整学生答案，
  按 (question_id, context) 聚合为 **155 份答案卷**；每卷仅保留被测得分点
  （与金标同口径），专家总分 = Σ 金标命中点权重。
- 抽样：按专家得分率排序后**等距抽取 36 卷**，覆盖 0 分～满分全分数段；
  覆盖语文/历史/地理/政治四科。
- 判定口径：Point-Acc=有答判定一致率；等价给分率=金标命中点中获得任一分数
  的比例；ScoreCorr=预测总分与专家总分 Pearson；MAE 同口径。

## 3. 关键发现与调优实验

### 3.1 阈值扫描：has_answer 0.5 → 0.75（环境变量 `RUBRICSPAN_MRC_THRESHOLD`）

| 指标 | 0.5（默认） | 0.75 |
| --- | --- | --- |
| Point-Acc | 0.784 | 0.778 |
| 等价给分率 | 0.974 | 0.957 |
| ScoreCorr | 0.9574 | **0.9580** |
| MAE | 1.89 | **1.67** |
| TP/FP/FN/TN | 112/33/3/19 | 110/32/5/20 |

**结论：维持默认 0.5。** 提高阈值几乎不减少误报（33→32）反而损失正确命中
（FN 3→5）——残余误报是**高置信判定**（如 >0.98），不是低置信噪声。

### 3.2 高置信分歧的本质（BC-001/BC-002）

抽检最大偏差卷 SAS-CHN-137（pred 12/12 vs 金标 3/12）：系统对"选D""选A"
等内容以 >0.98 置信抽取到原文片段。分歧源于三方面叠加：

1. **选择型得分点的固有歧义**："选A得1分/选D得2分"类点在讲解式作答中可同时
   出现字面内容；
2. **打标口径保守**：LLM 打标按"严格对应得分点语义"标注，系统按"字面命中 +
   别名表"判定；
3. **别名表覆盖有限**：超出 alias 枚举的改写由 MRC 泛化兜住，但金标未必承认。

→ 处置：登记 bad-cases BC-002，需**人工抽检仲裁**（区分漏标与误判）后决定
是否进入再打标/增量微调闭环；在此之前 Point-Acc 78% 应理解为该口径下的下界。

### 3.3 相似度兜底的长度效应（BC-003）—— 实验否决句级方案

假设：全文均值池化使"同题长答案"对任意得分点的 cos 整体抬升；改用
**句级最大值**应拉开命中/未命中分布。

实测（`scripts/m7_sim_sentence_experiment.py`，167 个点对，快照版权重）：

| 方案 | AUC | 召回@0.60 | 误报率@0.60 |
| --- | --- | --- | --- |
| 全文均值池化（现状） | **0.697** | 0.574 | **0.308** |
| 句级最大值 | 0.599 | 0.730 | 0.789 |

**结论：否决句级最大值方案，维持全文均值池化。** 句级 max 让同题的所有短句
都高分（误报率飙至 78.9%），全文池化的"按比例稀释"反而是有效的隐式正则。
长度自适应阈值可作后续备选，但当前兜底给分仅 +9 分、影响面小，优先级降低。
